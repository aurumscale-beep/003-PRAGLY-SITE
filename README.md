# Pragy — Proteção e Controle

Landing page responsiva para a Pragy, empresa de dedetização e controlo de pragas. O projecto foi desenvolvido em React, Vite e Tailwind CSS, com foco em conversão por WhatsApp, navegação mobile e uma identidade visual verde/off-white.

## Conteúdo da home

A página inclui hero com chamada de orçamento, secção institucional, serviços de controlo de pragas com imagens reais, CTA luminoso, mapa de atendimento em São Paulo e acesso directo ao WhatsApp **+55 11 98193-6639**.

## Desenvolvimento local

```bash
pnpm install
pnpm dev
```

## Publicação

O directório `docs/` contém a compilação estática preparada para o GitHub Pages. O site publicado é servido directamente a partir da branch `main` e da pasta `/docs`.
